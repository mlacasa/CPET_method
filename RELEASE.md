# Review status

Version 0.2.0 is shared publicly during peer review at
[mlacasa/CPET_method](https://github.com/mlacasa/CPET_method).
The manuscript and software are under review, and updates may follow reviewer
feedback. The repository provides the reusable implementation, tests, synthetic
example and documented verification scope. Record the Git commit as well as
the package version when using a review snapshot.

The final journal citation, reuse license, release tag and archival DOI have not
been assigned. Public access is provided now; no particular reuse license is
claimed. A publication snapshot can be archived once the final version is fixed.

Only the standalone software and its documentation are shared here. Clinical
workbooks, participant-level study data, reviewer correspondence and the private
study workspace are not part of this repository. Reproducing all manuscript
analyses requires the restricted study inputs described in Data availability.
